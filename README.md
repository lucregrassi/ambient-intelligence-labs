# Ambient Intelligence — Labs

Lab material for **Ambient Intelligence (80188)**, MSc in Robotics Engineering, University of Genoa.
Teacher: Lucrezia Grassi — `lucrezia.grassi@unige.it`

| | Lab | What you do | How to open it |
|---|---|---|---|
| **1** | [PIR from the Tuya cloud](lab1-tuya-pir/) | Pair a motion sensor, create your own cloud project, and read the sensor over a REST API from Python | [Instructions](lab1-tuya-pir/README.md) — runs on your own laptop, with the sensor |
| **2** | [Magnetic indoor localization](lab2-magnetic-localization/) | Record the magnetic field while walking a corridor, build a map of it, and work out where you were | [Instructions](lab2-magnetic-localization/README.md) — runs in Google Colab |
| **3** | [Classroom ontology in Protégé](lab3-classroom-ontology/) | Describe the room you are sitting in as an ontology, and let the reasoner work out three things about it that nobody typed | [Instructions](lab3-classroom-ontology/README.md) — runs in Protégé on your own machine |
| **4** | [Bayesian networks with pyAgrum](lab4-bayesian-networks/) | Build a network that works out what is going on in a room from three sensors, then replace the numbers you invented with numbers counted from a log | [Instructions](lab4-bayesian-networks/README.md) — runs in Google Colab |
